# 0.46 제작 원본

reference.png는 승인한 장애물 시안이며 obstacles.png(4×4), hero.png(4×3), arms.png(3×2)는 해당 시안과 0.45 캐릭터를 참조해 이미지 생성으로 제작한 투명 원본이다. 원본은 수정하지 않고 보관한다.

장애물 셀: 솥, 칼날, 소켓, 벽, 석판, 발광 석판, 나무봉, 사슬, 추, 발판, 물줄기, 물보라, 증기, 먼지, 손잡이, 돌 받침. 캐릭터 셀: 대기, 왼쪽 이동, 점프, 숙이기, 오른쪽 밀기, 왼쪽 밀기, 뒷모습, 오른쪽 이동, 착지, 피격, 호흡, 일어나기. 팔 셀: 천 상박/가죽 하박/장갑, 금속 상박/하박/장갑.

제작 지시: 승인 시안의 푸른 석조·이끼·횃불, 닳은 주철·금속 날·갈라진 나뭇결과 금발/녹색 후드/가죽 장비를 유지. 각 물체와 자세는 투명 셀에 독립 제작. 팔은 위에서 아래로 정렬한 어깨–팔꿈치/팔꿈치–손목 조각과 손잡이를 쥔 작은 장갑으로 제작. 사진·벡터 대신 세밀한 픽셀 윤곽과 재질 명암을 사용.

`tools/obstacle_art.py`는 알파 경계에서 자르고 가장 가까운 픽셀 보간으로 크기/셀을 배치한다. 원화나 게임 화면을 다시 그리지 않는다. `python3 tools/build_pixel_sprites.py --check`로 원본과 출력을 검사한다(Pillow 11.3.0).
