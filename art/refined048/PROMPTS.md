# 0.48 제작 원본

기본 이미지 생성 도구로 제작했다. `tools/preparation_art.py`는 투명 셀을 잘라 맞추고 아틀라스에 배치하며, 배경을 리사이즈한다. 그림을 재해석하거나 절차 도형으로 대체하지 않는다. 전체 재생성 검사는 `python3 tools/build_pixel_sprites.py --check`.

| 파일 | 참조 및 제작 지시 |
| --- | --- |
| rear_armor.png | art/refined045/armor.png와 hero.png 참조. 4열×5행 투명 장비 원화. 방패 4개 안쪽 나무·가죽 손잡이, 투구 4개 뒤통수·뒷목, 가죽/사슬/판금 등판, 바지와 신발 뒷모습, 반지·목걸이 뒤쪽 고리·후드. 우측을 향하는 캐릭터의 뒤쪽 사선 시점, 금속·가죽 재질과 픽셀 명암 유지, 얼굴/인체/문자/바닥 그림자 제외. |
| camp.png | art/refined045/arena.png 참조. 2.5:1 지상 출정 준비 배경. 푸른 돌벽·횃불, 중앙 던전 입구와 빈 바닥, 왼쪽 비품·상자, 오른쪽 작은 상인 노점. 별도 렌더링할 플레이어를 원화에 포함하지 않으며 UI/문자 제외. |
| menus.png | art/refined045/armor.png 참조. 3열×2행 투명 아이콘. 교차 검과 갑옷, 가죽 가방, 상인 노점, 녹색 성장 수정, 보관 상자, 기록 책. 일정한 명도·픽셀 밀도·재질, UI 테두리/문자/배경 제외. |

뒷면 셀의 기본/파생 장비 연결과 실제 불투명 영역은 생성된 `PreparationAtlas.kt`에 기록한다. 출처 원화는 이 폴더에 보존한다.
