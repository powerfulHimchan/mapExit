# 정교한 도트 전투 제작 원본 · 0.45

`reference.png`는 사용자가 선택한 2번 시안이다. 나머지 다섯 PNG는 이 시안을 참조해 이미지 생성으로 새로 제작한 실제 게임용 원본이다. 시안 그림을 게임 화면처럼 보여주는 용도로만 쓰지 않고, 각 원본을 아틀라스로 변환해 앱에서 직접 읽는다.

| 원본 | 제작 지시와 셀 순서 |
| --- | --- |
| hero.png | 4×4 투명 아틀라스. 시안의 금발·녹색 후드·가죽 벨트/부츠, 3.5등신에 가까운 체형, 머리카락의 명암과 옷의 주름/봉제선 유지. 앞 8칸은 팔 아래 부분을 분리한 몸체: 대기·준비·휘두른 뒤·방어·회피·피격·쓰러짐·호흡. 뒤 8칸은 천 소매·가죽 보호구·손, 금속 소매·보호구·손, 가죽/금속 몸통. 장착 무기는 몸에 그리지 않는다. |
| monsters.png | 4×4 투명 아틀라스. 슬라임·기사·박쥐·거미·골렘·도깨비불·보스 각각 대기/공격 2칸, 마지막 2칸은 도깨비불 피격/소멸. 시안의 도깨비불과 같은 청록 발광 및 모든 종의 세밀한 재질 명암. 기사는 무기 없이 제작해 실제 게임 무기를 붙인다. |
| weapons.png | 4×5 투명 아틀라스. 검 4종, 창 4종, 해머 4종, 클로 4종, 채찍 4종. 손잡이 아래, 날 위의 방향. 금속 면·가죽 손잡이·금색 부속을 시안과 같은 질감으로 제작한다. |
| armor.png | 4×5 투명 아틀라스. 방패 4, 투구 4, 몸통 3, 바지 3, 신발 3, 반지·목걸이·후드 깃. 몸통과 바지는 빈 착용 외피로 제작한다. 리벳·봉제선·겹친 판금과 가죽의 명암을 유지한다. |
| arena.png | 인물/UI 없는 전투 배경. 푸른 회색 돌벽, 깨지고 닳은 원근 바닥, 이끼, 양옆 석주와 따뜻한 횃불. 시안의 환경 재질과 같은 방향으로 제작한다. |

공통 제작 조건: 완성도 있는 세밀한 픽셀 그림, 어두운 외곽선, 왼쪽 위의 따뜻한 빛과 차가운 접촉 그림자. 단순한 기하 도형·문자·UI·바닥 그림자를 자산에 합치지 않는다. 캐릭터/장비는 실제 투명 알파를 사용한다. 이미지 생성 기본 도구를 사용했다.

`python3 -m pip install Pillow==11.3.0` 후 `python3 tools/build_pixel_sprites.py`로 아틀라스를 생성한다. `--check`는 픽셀과 메타데이터를 원본에서 재생성해 비교한다. 원본을 수정할 때는 별도 버전으로 저장하고, 셀 경계·손잡이·어깨·착용 영역도 함께 확인한다.
