# mapExit

오프라인으로 플레이하는 안드로이드 도트 던전 탐험 게임.

- 세로 화면 네 구역과 버튼 두 개
- 통로 자동 이동, 갈림길에서 방향 선택
- 탐험은 1인칭, 전투는 3인칭의 공격·방어 교대 방식
- 무기는 검·창·해머·클로·채찍의 5종, 무기별 한손·양손 및 방패 조합 적용
- 머리·왼손·오른손·몸통·바지·신발·목걸이·반지 2칸의 장비 슬롯 총 9칸
- 반지는 스테이터스를 조정하고, 목걸이는 탐험·함정·상점·보상 등 게임 요소에 영향
- 층당 약 5분, 50층 클리어 후 엔딩과 새 회차 시작
- 10층마다 보스, 보스 처치 후 지상에서 해당 층으로 이동하는 장치 활성화
- 일반 사망 시 소지 아이템·착용 장비·소지 골드 소실, 캐릭터 성장과 보관 골드·장치 유지
- 50층 클리어 후 성장·소지/보관 골드·이동 장치 초기화, 1층부터 재도전
- 매 클리어마다 새로 계승할 장비 한 개를 반드시 선택
- 이전에 계승한 장비들은 착용 여부와 관계없이 모두 자동 계승

전체 규칙과 구현 기본안은 [게임 설계](docs/game-design.md)를 참고한다.

무기별 확정 효과, 수치 초안과 검증 결과는 [무기 밸런스](docs/weapon-balance.md)를 참고한다.

밸런스 설정과 Python 표준 라이브러리만 사용하는 독립 검증 도구를 포함한다. 저장소 루트에서 다음 명령으로 실행한다.

```sh
python3 tools/check_weapon_balance.py --check
```

현재는 기획과 밸런스 검증 단계이며, 안드로이드 앱 소스와 실행 가능한 APK는 아직 포함하지 않는다.
