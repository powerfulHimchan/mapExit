# mapExit

오프라인으로 플레이하는 안드로이드 도트 던전 탐험 게임.

- 세로 화면 네 구역과 버튼 두 개
- 통로 자동 이동, 갈림길에서 방향 선택
- 탐험은 1인칭, 전투는 3인칭의 공격·방어 교대 방식
- 층당 약 5분, 50층 클리어 시 엔딩
- 10층마다 보스, 보스 처치 후 지상에서 해당 층으로 이동하는 장치 활성화
- 사망 시 소지 아이템·착용 장비·소지 골드 소실, 캐릭터 성장과 보관 골드·장치 유지

전체 규칙과 구현 기본안은 [게임 설계](docs/game-design.md)를 참고한다.

현재는 기획 문서 단계이며, 앱 소스와 실행 가능한 APK는 아직 포함하지 않는다.
