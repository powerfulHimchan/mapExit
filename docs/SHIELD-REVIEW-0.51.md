# 방패 위치 재검토 · 병합 전 확인용

0.50에서는 손잡이를 맞춘 방패가 등판을 많이 덮었고, 방패 위에 상박까지 다시 그려 어깨에 부착된 것처럼 보였다.

이번 변경은 왼손을 왼쪽 아래로 내려 방패가 왼쪽 허벅지 옆에 놓이게 한다. 방패 최대 높이는 23에서 20 논리 픽셀, 최대 폭은 18에서 16으로 줄인다. 방어 시에는 얼굴 전체를 가리지 않는 왼쪽 가슴 위치로 올린다. 상박은 방패 뒤에, 하박과 손은 안쪽 손잡이 앞에 그린다. 대기·공격·강공격·방어·회피와 네 방패, 가죽/강철 장비를 실제 Android Canvas에서 캡처한다. 실행 중인 게임 Activity에서도 전투 대기·공격·방어·NPC 화면을 별도로 캡처한다.

상태: 사용자에게 실제 구현 캡처를 제시한 뒤 확인을 받기 전까지 main에 병합하지 않는다.
