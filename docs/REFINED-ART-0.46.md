# 장애물 원화와 팔 동작 · 0.46

승인한 시안의 5종 장애물을 분리 원화로 연결했다. 솥/물줄기/물보라/증기, 칼날/소켓, 압착벽, 발광 석판/추, 나무봉/쇠사슬이 기존 상태와 시간에 따라 움직인다. 물은 위험한 쪽 바닥으로 흐르며, 칼날의 완전 수납과 나무봉의 숙이기 허용 시간은 기존 판정을 그대로 사용한다. 칼날은 실제 이동 구간 안에 있어야 하므로 시안 보드의 독립 확대 그림보다 작게 표시된다.

장애물 캐릭터는 12가지 완성 자세를 사용한다. 대기·좌우 이동·점프·착지·숙이기·밀기·피격을 선택하고 착용 방어구를 자세별 위치에 그린다. 별도의 시안 화면을 앱 화면으로 대체하지 않는다.

전투 팔은 단순 중간점 팔꿈치와 가변 길이 대신 고정된 두 뼈의 도달 범위로 계산한다. 손이 닿을 수 있는 위치를 먼저 구하고 무기 손잡이를 거기에 배치한다. 양손 무기는 양팔이 같은 손잡이에 닿는 범위로 제한한다. 상박/하박의 새 원화는 수직 축과 관절 중심에 정렬했고, 손은 작게 조정했다. 팔끝과 손목은 무기 회전에 맞춰 연결한다. 공격 타격 시계, 피해·저장·턴·장비 규칙은 동일하다.

검증은 전체 core/lint/Android 검사 외에 각 장애물의 실제 UI 일반/작은 화면, 단계별 원화 렌더링, 무기별 공격/강공격/방어/회피/피격 및 양손 장비 캡처로 수행한다. 자동 통과만으로 스타일이나 장착 연결이 맞다고 판단하지 않고 캡처를 별도로 확인한다.
