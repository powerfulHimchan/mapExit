# 특수 스테이지 기획안 — 검토 대기

사용자 확정 요구: 무작위로 등장하며 약 15층마다 한 번 정도 만난다.
아래 내용은 이번에 정리한 제안이며 실행 코드는 아직 구현하지 않는다.

## 등장과 진입

- 매 회차 11~14층, 26~29층, 41~44층 중 각각 한 층을 무작위로 정한다. 50층까지 총 3회, 평균 간격 15층이다.
- 보스(10층 단위)·정예(5층 단위) 층과 겹치지 않는다.
- 선택한 층의 접근 가능한 일반 통로에 특별 포털을 배치한다. 기본 출구와 진행 동선은 유지한다.
- 발견하면 스테이지 이름·위험·예상 보상을 보여주고 ‘들어가기 / 지나가기’를 선택한다. 입장은 선택 사항이다.
- 특별 구역은 별도 작은 맵이다. 원래 층 번호는 유지하고 완료·중도 귀환 시 원래 포털 앞의 안전한 위치로 돌아온다.

## 스테이지 종류

각 포털은 아래 네 종류 중 하나를 동일 확률로 선택한다.

| 종류 | 플레이 | 보상 제안 |
|---|---|---|
| 보물 금고 | 무기·방어구·장신구가 든 세 상자 중 하나만 선택. 장비 종류와 예상 수치는 선택 전에 표시 | 선택 장비 1개(현재 구간 일반 장비보다 등급 +1, 최대 7) + 50+현재 층×5 G |
| 시련의 투기장 | 정예 몬스터 두 마리와 연속 전투. 중간 자동 회복 없음, 회복약 사용 가능 | 현재 구간 등급의 무기 1개에 양수 추가 옵션 2개 + 상급 회복약 1개 |
| 잊힌 회복 정원 | 전투 없이 정원의 제단을 한 번 사용 | 즉시 최대 HP의 60% 회복 + 상급 회복약 1개 |
| 떠돌이 교환소 | 현재 구간의 장비 3개와 상급 회복약 거래. 일반 상점처럼 장착 비교 제공 | 장비 가격 20% 할인, 상급 회복약은 60G에 최대 3개 구매 |

- 투기장 보상은 두 전투를 모두 이겨야 한 번 지급한다. 도주 성공 시 도전은 끝나며 포털로 복귀하고 완료 보상은 없다. 재도전은 허용하지 않는 안이다.
- 투기장의 몬스터 처치·경험치·골드는 실제 처치한 만큼 정상 기록한다. 나머지 종류는 전투 없이 이용한다.
- 상점 할인 목걸이는 교환소 할인 가격에 추가 적용한다(상급 회복약 48G). 판매 가격은 기본 가격 기준을 유지해 반복 매매 이익이 생기지 않게 한다.

## 반복 이용과 저장

- 포털 위치·종류·상자 내용·상품 목록은 회차가 시작할 때 정한 결과로 고정한다. 저장을 다시 불러오거나 같은 층을 재생성해도 바뀌지 않는다.
- 각 포털은 회차당 한 번 이용한다. 지나가기는 소비하지 않는다. 입장 후 중도 종료·도주·사망하면 그 회차에는 다시 이용할 수 없다.
- 완료 보상·구매·상자 선택은 확정 시 저장하고, 전투 중 종료하면 해당 전투·남은 체력·진행 단계로 복원한다. 중복 지급은 막는다.
- 사망과 탐험 포기는 기존 장비·아이템·소지 골드 손실 규칙을 따른다. 포털 이용 상태는 같은 회차에서 유지한다.
- 다음 회차에는 등장 층·종류를 새로 정한다. 일반 층/출구, 보스/계승, 의뢰 목표가 특별 구역의 별도 맵 때문에 잘못 진행되지 않도록 분리한다.
- 특수 스테이지 전용 업적은 추후 콘텐츠 확정 후 별도로 정한다.

## 화면과 검증

- 특별 포털은 일반 출구와 구별되는 보라색 문양·도트 아트로 표시한다. 먼 거리에서도 기존 원근 크기 제한을 적용한다.
- 들어가기 전 위험·보상, 입장 후 남은 전투/선택/구매 횟수를 표시한다.
- 진입·지나가기·완료·도주·사망·저장 복원·회차 전환, 3회 등장 및 간격, 접근성, 작은 화면과 보상 중복 방지를 검증한다.
