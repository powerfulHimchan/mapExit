# 도전형 특별 스테이지 — 0.27.0

## 등장과 입장

- 매 회차 11~14층, 26~29층, 41~44층에서 각각 무작위 한 층을 선택한다. 50층까지 3회, 등장 간격은 12~18층이다.
- 각 포털은 7종 중 하나를 동일 확률로 선택한다. 회차의 등장 층·종류·도전 맵·보상은 저장과 재방문으로 재추첨되지 않는다.
- 포털은 일반 던전의 접근 가능한 빈 통로에 배치한다. 몬스터·상자·회복·NPC·상인·함정·보스·정예·출구의 기존 배치를 덮어쓰지 않는다.
- 포털에서 안내를 확인하고 시작하거나 돌아갈 수 있다. 안내만 보고 돌아가는 것은 사용 횟수를 소비하지 않는다.
- 실제 시작하면 회차당 한 번 소비한다. 성공·실패·포기 뒤에는 같은 포털에 다시 도전할 수 없다. 사용 상태는 일반 던전 재생성·사망·귀환 후에도 유지되며 다음 회차에 초기화된다.

## 7가지 도전

모두 기존 던전과 같은 1인칭 미로이며 몬스터·일반 서비스·전투는 없다. 활성 도전 화면에는 미니맵을 표시하지 않는다. 방향 선택 규칙은 일반 던전과 같고 이동 버튼은 한 번에 한 칸씩 이동한다.

| 도전 | 제한 | 규칙과 단서 |
|---|---|---|
| 길 잃은 미궁 | 90초 | 벽 표식과 방위를 기억하며 출구 찾기 |
| 기억의 회랑 | 지도 7초 공개 후 60초 | 전체 지도에 시작·출구 표시. 기억 완료로 일찍 출발 가능. 출발하면 지도 숨김 |
| 무너지는 유적 | 70초 | 떠난 칸이 3초 뒤 벽으로 붕괴. 안정된 경로의 문양과 갈림길 버튼의 문양을 비교. 붕괴 시각에 그 칸에 서 있거나 출구가 막히면 실패 |
| 봉인의 방 | 90초 | 입구의 해·달·별 순서대로 제단 작동 후 출구 개방. 제단 배치는 고정, 순서는 회차별 무작위. 입구에 돌아가면 순서 재확인 가능. 오작동마다 10초 차감 |
| 꺼져가는 횃불 | 90초, 횃불 22초 | 불이 줄면 실제 시야가 어두워지고 짧아짐. 출구 경로의 화로에서 한 번씩 22초로 보충. 불이 완전히 꺼지면 실패 |
| 칼날의 회랑 | 90초 | 칼날·낙하물·닫히는 벽을 통과. 실제 주기에 맞춰 대기/통과 선택. 실패마다 8초 차감, 실수 3회면 종료 |
| 한정된 발걸음 | 최단 경로 +4칸 | 준비 화면에서 시간 제한 없이 전체 경로 계획. 출발 후 지도 숨김. 뒤로 이동도 한 칸 소비하고 방향 전환·벽에 막힌 입력은 소비하지 않음. 시간 제한 없음 |

칼날은 4초 주기 중 1.4~2.6초, 낙하물은 1.8~3.0초에 통과할 수 있다. 벽은 0~0.9초 및 3.1~4.0초에 완전히 열린다. 화면의 기계 동작과 안전 표시는 이 판정과 같은 시간을 사용한다. 대기 버튼은 도전 내 시간을 0.5초 진행하며, 직접 누르지 않아도 활성 화면의 시간은 흐른다.

## 중단·복원·결과

- 안내 화면에서는 시간이 흐르지 않는다. 일시정지와 앱 백그라운드 진입은 시간·횃불·붕괴·장애물을 모두 멈춘다. 일시정지 화면은 지도와 던전 장면을 숨기고 계속/포기를 제공한다.
- 저장에는 활성 미로, 원래 던전, 위치·방향, 제한·진행도, 제단·화로 상태, 붕괴 시각, 장애물 주기, 보상 지급 여부를 함께 저장한다.
- 성공·실패·포기는 결과 화면에서 확인 후 원래 포털 위치·방향으로 복귀한다. 도전 실패는 일반 사망 손실을 적용하지 않는다.
- 원래 층 번호·장비·체력·경험치·의뢰·도감·일반 처치/상자/함정 횟수는 도전으로 변경하지 않는다. 도전 중 일반 장비·성장·가방·귀환 메뉴는 열지 않는다.

## 보상·기록·연습

- 성공 시 골드 `60 + 입장 층×4`를 한 번 지급한다.
- 미궁·기억·봉인·횃불: 상급 회복약 2개.
- 붕괴·장애물·발걸음: 다음 10층 구간 등급의 ‘도전자의’ 무기 1개 + 상급 회복약 1개. 최대 등급은 기존 장비 상한을 따른다.
- 결과 화면은 실제 장비 아이콘·능력치와 바로 장착을 제공한다. 지급 이후의 아이템에는 기존 사망·판매·계승 규칙을 적용한다.
- 기록 메뉴의 ‘특별 도전 기록’에 종류별 도전/성공 횟수, 최단 시간과 최소 이동 칸 수를 보존한다. 두 최고 값은 각각 독립된 기록이다.
- 테스트 메뉴 → 특별 도전 7종에서 각 종류를 연습할 수 있다. 연습은 보상·업적·일반 진행·도전 기록을 변경하지 않으며 종료하면 원래 게임을 복원한다.
