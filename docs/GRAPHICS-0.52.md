# 0.52 그래픽 변경

- 런처: 사용자 선택 2번 계단 원화. 기본/원형/적응형 아이콘에 동일 이미지를 사용한다.
- 출정 준비: 기존 실제 화면 시계와 좌우 방향별 보행을 유지하고 travel 진폭을 0.105에서 0.24로 확대한다. 화면 폭 기준 왕복 범위 21% → 48%, 약 2.29배다. 자동 반복이며 입력이 필요 없다.
- 이동 중 몬스터: 5지역 35종의 전투 idle_0 프레임에서 실제 알파 윤곽을 잘라 사용한다. 정예도 해당 종 원화를 사용한다.
- 장애물: 솥/칼날/협착 벽/기억 돌/천장 나무봉의 진입 장면 부품을 그대로 조합한다. 함정 종류 변경도 렌더 캐시에 반영한다. 크기를 높여 접근 중 형태를 알아볼 수 있게 한다.
- 회복 장소: 민트색 수정과 둥근 석조 제단. 사용 후에는 같은 형상을 어둡고 무채색으로 표시한다. 접근·진입·재방문에 같은 원화를 쓴다.
- 피해: 0~9 및 !의 흰색/금색/빨강 이미지 33개를 필요한 순서대로 조합한다. 박스·패널 테두리 없이 글리프 윤곽만 사용한다. 일반 피해는 흰색, 치명타는 큰 금색, 플레이어 피격은 빨강이다.
- 문구: 치명타!, 방어, 완전 방어, 회피, 빗나감, 행운, 방패 파괴, 빈틈 공격, 공격 경감, 연속 공격, 빈틈 발생, 반격의 12개 투명 이미지. 전체 상세 효과는 기존 행동 로그와 접근성 설명에 유지한다.
- 기존 타격 시점, 연속 공격·반격 단계, 등장/상승/소멸 시간, 게임 수치·저장 형식은 유지한다.

## 원화와 재현

`art/refined052`에 생성된 숫자·문구·회복 제단 원화와 선택된 아이콘 원본을 보관한다. `tools/feedback_art_052.py`는 원화를 잘라 배치하고 크기만 조절하며, 폰트로 다시 그리지 않는다. 장애물에는 `obstacle_parts_046.png`, 몬스터에는 `combat_monster_motion.png`를 직접 재사용한다.

```sh
python3 tools/build_pixel_sprites.py --check
./gradlew :core:test :app:lintDebug :app:assembleDebug --no-daemon
./gradlew :app:connectedDebugAndroidTest --no-daemon
```

`Graphics052Test`는 알파 여백, 최대 정수 조합, 35종 몬스터 원화 일치, 서로 다른 5종 함정, 사용 후 수정, 동일 맵 캐시 갱신, 벽 가림, 출정 이동 연속성, 런처 리소스를 검사한다. 실제 Activity에서 일반/치명타/피격/방어/완전 방어/회피/빗나감/효과와 탐험 화면을 캡처한다. 기존 전체 Android 검사에는 자동 출정 애니메이션과 좁은 화면 피해 위치 검사도 포함된다. 전용 Requested graphics preview 워크플로는 이번 변경 캡처만 별도 아티팩트로 모은다.
