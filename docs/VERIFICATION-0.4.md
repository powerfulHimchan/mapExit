# MapExit 0.4.0 검증

기준 main은 `205f134`입니다. 상자·NPC·상인 조우, 단일 의뢰, 상자 몬스터, 빠른 자동 함정과 판매 목록을 검증합니다.

## 자동 검사 범위

- 조우 진입 시 이동 정지, 두 버튼 선택, 거절 후 이동 및 재방문, 저장 복원.
- NPC 의뢰 하나의 고정 제시, 수락/거절, 기존 의뢰 유지, 보상 중복 방지와 50층의 가능한 의뢰만 생성.
- 상자 보상/몬스터 분기, 상자 1회 개봉, 미션 진행 1회 반영, 상자 전투 종료 후 탐험 복귀.
- 판매 시 장착 슬롯 표시, 같은 이름의 장비 ID 구분, 양손 무기 해제, 판매 목록 제거와 중복 판매 방지, 저장 후 재확인.
- 다섯 함정의 1초 준비·기억 표시·2초 입력·0.9초 결과 자동 복귀, 성공/실패 및 사망 처리.
- 이전 저장의 함정 안내/NPC 메뉴 호환과 기존 전투·50층·장비 회귀 검사.
- Android 11에서 실제 버튼/목록 터치, 실시간 함정 타이머와 성공/실패 자동 복귀, 작은 화면 검증. PNG 화면은 CI 결과물로 수집해 검토합니다.

로컬 환경의 Gradle 다운로드 연결이 제한되어 빌드·순수 Kotlin 테스트·lint·Android 계측 테스트 결과는 PR과 main의 GitHub Actions를 기준으로 확인합니다. 실기기 플레이와 난이도 체감은 별도입니다.
