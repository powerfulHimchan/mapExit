# MapExit 0.3.0 검증

기준 main은 `4c14328`입니다. 벽 두께, 3인칭 전투 전환, 승리 확인, 함정 설명, 적 HP와 피해량 피드백을 검증합니다.

## 로컬 검사

- 기존 47개와 전투·함정 피드백 10개, core 테스트 총 57개 통과.
- Android 앱과 계측 테스트 Kotlin 컴파일, lint 오류 0.
- 승리 보상의 1회 지급·확인 전 저장/복원, 보스·50층·계승 연계 확인.
- 적/플레이어 실제 HP 감소, 치명타·방어·회피·빗나감, 사망의 피드백 분리 확인.
- 실제 던전 함정 진입 및 다섯 함정의 설명 대기·확인·시작, 설명에서의 타이머 정지 확인.
- 새 필드 없는 기존 v1 저장과 진행 중 함정의 이어하기 확인.

## Android 11 자동 검사 구성

기존 준비·직접 조작·작은 화면 테스트와 전투 피드백·다섯 함정 설명을 포함한 계측 테스트 3개를 실행합니다. 실제 A/B 터치로 공격·방어·승리 확인·함정 시작을 검증하며, 승리 화면에서 새 모델로 복원해 보상이 유지되고 피해 팝업이 다시 재생되지 않는지 확인합니다.

기본 화면과 720×1280 화면에서 벽 단면·3인칭 구도·숫자 HP·적/플레이어 피해·승리·함정 안내를 포함한 PNG 19장을 수집합니다. 실패 시에도 가능한 화면과 검사 보고서를 보존합니다. 최종 실행 결과는 변경 PR과 main의 GitHub Actions에 기록됩니다.

실제 휴대폰 플레이와 난이도 체감은 에뮬레이터 자동 검사와 별도입니다.
