# MapExit 0.5.0 그래픽 검증

기준 main은 `af19d1c`입니다. 가로 480도트 장면과 26종 원화, 원근 재질·배경·장비 아이콘을 검증합니다.

## 검사 범위

- 직접 그린 좌표/팔레트 원본과 Kotlin atlas의 일치 검사. 플레이어·NPC·상인·기사·보스는 32×48 도트이며 작은 몬스터와 상자, 시설·무기·장비는 비율에 맞는 원화를 사용합니다.
- 기존 core 테스트 67개, Android lint와 APK 빌드.
- Android 11 계측 테스트 6개: 기존 조우·판매·함정·저장·전투·작은 화면 검사와 그래픽 갤러리.
- 다섯 무기와 방패의 손 위치, 기사·박쥐·보스, 회복 장소·출구·준비·계승·가방·상점·판매·다섯 함정 및 승리/피격 화면.
- Android 비트맵으로 전체 26종 원화 atlas를 실제 렌더링하고, 일반 게임 화면과 함께 PNG 총 41장을 수집해 검토합니다.
- 최근접 보간, 일정한 원화 크기와 카메라 기준점, 작은 화면의 텍스트/버튼/오버레이 배치를 확인합니다.

재질 비트맵과 원화는 최초 사용 시 생성해 재사용합니다. 시각 효과는 게임 난수를 사용하지 않습니다. 빌드와 기기 검사 결과는 PR과 main의 GitHub Actions에 기록하며, 실제 휴대폰 프레임률과 플레이 체감은 별도입니다.
