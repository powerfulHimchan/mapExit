# 정면 준비·NPC 대화·상점 가격·성장 아이콘 · 0.49

출정 준비에 정면을 보는 금발·녹색 주인공 몸체를 새로 연결했다. 정면 장비의 머리·몸통·바지·신발·목걸이를 별도 위치에 배치하며 팔·손·무기·방패는 실제 장착 상태를 사용한다. 정면에서 플레이어 오른손은 화면 왼쪽이며, 양손 무기의 손잡이는 두 팔이 닿는 범위에 둔다. 전투·상자 장면은 기존 뒷모습과 뒷면 장비를 유지한다.

NPC 네 역할과 상인은 지도·그릇·의료 가방·약초/물약·등불의 별도 원화를 사용한다. 전투와 같은 플레이어·배경 렌더러를 사용하고 대화창 높이를 측정해 그 아래에 두 인물을 배치한다. 작은 화면의 긴 대화는 기존 스크롤과 이용 불가 안내를 유지한다. 의뢰·기부·회복·보상 수치와 저장 형식은 바꾸지 않는다.

상점 카드의 가격은 구매 처리/상세 화면과 같은 `Equipment.buyPrice`를 사용한다. 상인의 목걸이 할인·강화도 반영하며 소지금이 부족하면 붉은 가격을 표시한다. 카드 이름의 기존 접근성/클릭 동작을 유지하고 가격을 상태 설명에도 제공한다.

성장의 체력·공격·방어·민첩·치명타 확률·치명타 공격력·행운 및 전체 회복에 8개의 도트 아이콘을 연결했다. 능력치 아이콘을 공유하는 요약 화면에도 같은 원화를 사용하며 수치와 설명·성장 규칙은 유지한다.

원화 재생성, 전체 core/lint/기기 검사, 정면의 무기 5계열·NPC 역할별 저장 불변 렌더링, 일반/작은 화면의 준비·5종 대화·성장 캡처로 검증한다. 상점에서는 표시된 정상/할인 가격으로 실제 카드를 눌러 구매하고 소지금 차감을 확인한다.
