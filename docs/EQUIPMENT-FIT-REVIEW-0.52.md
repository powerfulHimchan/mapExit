# 몸 윤곽을 유지하는 갑옷과 팔에 고정된 방패 · 재검토

갑옷 아이콘을 몸통 일부에 붙이던 처리를 교체한다. 원래 192px 몸체의 목깃·어깨·허리·옷자락 윤곽 안에서 갑옷 소재를 합성하여 기본 옷과 갑옷이 이중으로 보이지 않게 한다. 원본 몸체의 모든 알파 값, 허리띠, 머리와 팔다리는 유지한다. 8개 원화 자세와 프레임의 1px 상하 이동을 따른다.

방패의 독립적인 회전·크기 설정을 제거한다. 실제 손 위치를 아래 손잡이, 실제 팔꿈치를 위쪽 팔 고정 끈에 맞추는 두 기준점으로 위치·각도·크기를 한 번에 정한다. 팔과 방패를 따로 회전시키지 않는다.

실제 Android에서 가죽·사슬·판금 3종 × 8개 자세의 몸 윤곽 보존, 4종 방패의 손잡이·팔 고정 끈 위치, 40개 장비/동작 프레임, 실행 중인 앱의 전투/대화 화면을 검증한다. 전용 미리보기 작업은 이 검증과 캡처만 먼저 생성한다.

사용자가 실제 구현 화면을 확인하고 동의하기 전에는 main에 병합하지 않는다.
