# 전투 원화 재제작 · 0.45.0

## 이전 결과와 변경 범위

0.44는 기존 32픽셀 도트를 확장해 세부 표현을 보강했으며 제안한 시안의 체형·명암·질감을 재현하지 못했다. 0.45는 선택한 시안을 원본으로 보관하고, 이를 참조해 새로 제작한 이미지 자산을 앱에서 직접 사용한다. [원본과 제작 지시](../art/refined045/README.md).

- 몸체는 대기·공격 준비·공격 후·방어·회피·피격·쓰러짐·호흡의 8가지 그림이다. 기존 무기 5종의 동작 시계와 82개 프레임 키가 이 그림 및 분리된 팔·손·장비 위치를 선택한다. 82장의 별도 원화를 그렸다는 의미는 아니다.
- 몬스터는 7계열의 대기/공격 원화를 바탕으로 지역별 색과 기존 반응 동작을 연결한다. 도깨비불에는 별도의 피격/소멸 그림도 사용한다. 35종×18개 프레임 키는 630장 서로 다른 원화를 뜻하지 않는다.
- 무기 20종, 방어구와 액세서리 원본, 분리된 팔/손을 제작했다. 기본 장비 이름은 해당 무기/방어구 자산을 공유하며, 등급 색·실제 장착 규칙과 메뉴 아이콘의 접두 배지를 유지한다. 손에 든 장비에는 별도의 접두 배지 사각형을 띄우지 않는다.
- 배경도 새 돌벽·이끼·석주·원근 바닥을 사용한다. 지역 색과 빛의 미세한 깜박임을 별도로 적용한다. 전투 UI, 저체력 경고와 게임 규칙은 바꾸지 않는다.

## 동작 연결

전투 전경 캐릭터를 시안처럼 크게 표시하고, 새 원화는 소수 단위 배율도 픽셀 보간 없이 사용한다.

몸체 원화별 좌우 어깨, 투구/몸통/바지/부츠 영역 및 회전 각도를 기록했다. 팔과 손은 같은 원본의 별도 레이어를 사용하고 무기의 실제 손잡이 좌표에 연결한다. 회피·피격·쓰러짐에는 해당 몸체 그림을 사용한다. 새 몸체는 이미 자세별 다리 형태를 포함하므로 기존 도트의 다리 잘라 움직이기/팔 잘라내기를 중복 적용하지 않는다.

아틀라스 크기는 모두 4096 이하다. 몸체 2304×1344, 몬스터 3456×3888, 장비 1280×1152, 배경 960×640을 한 번 읽는다. 픽셀 보간은 사용하지 않는다. PNG 원본과 출력을 저장하고 Pillow 11.3.0으로 생성/검사한다.

## 검증과 수락 기준

기존 전체 core·lint·기기 검사와 모든 프레임/무기/방어구 검사를 유지한다. 새 기기 검사는 실제 전투 UI에서 시안과 같은 검/방패/도깨비불/저체력 장면을 만들고, 실제 일반 공격 입력 뒤 준비·타격·회복 모습을 일반/작은 화면에서 캡처한다. 원화 아틀라스 크기 검사는 새 셀 크기를 사용한다.

자동 테스트는 스타일 일치의 증거가 아니다. 실제 기기 캡처에서 머리카락·옷·장비·돌 재질을 시안과 대조하고, 공격 중 손잡이 연결·장비 크기·몸체/방어구 자름을 확인한 후 병합한다. 생성 원화나 별도 합성 시안을 실제 앱 캡처로 안내하지 않는다.
