# MapExit 0.8.0 준비 UI / 전투 동작 검증

- Core 87개: 기존 82개 + 연속 장착/해제, 탐험 중 장비 복귀와 저장, 가방 복귀, 무기별 준비·접촉·회복 동작, 강공격/무상태 변경 검사.
- Android 11 계측 12개: 기존 9개 + 6개 준비 메뉴의 로그 제거/4열 성장, 실제 전투 입력 잠금·치명타·빨간 플레이어 피해·사망 동작, 5무기/4몬스터의 3시점 렌더 검사. 기존 흐름에 2회 연속 장착과 복귀 검사를 추가합니다.

- 작은 화면에서 메인 장면 비중·두 행동 버튼·전투 결과/피해 숫자 분리·4열 성장·아이콘 메뉴 스크롤을 검사합니다.
- 메뉴/피해/무기/몬스터 동작 프레임을 추가해 PNG 105장을 수집하고 변경 화면을 검토합니다.
- Android lint, debug APK 빌드와 26종 도트 원화 일치 검사를 실행합니다.
