# 전투 화면 · 0.43.0

전투 인터페이스는 0.42 형태를 유지하고, 캐릭터·몬스터·장비·전투 배경 그래픽은 0.41 방식으로 복원한다.

- `FineSprites`와 `GearSprites`의 기존 도트 원화, 지역별 몬스터·배경, 원래 장비 착용 좌표를 사용한다.
- 0.42에서 추가한 세 WebP 원화와 `BattleArtwork` 연결을 제거한다.
- 전투 정보·현재 상황·차례 패널, 금속 테두리 버튼, 체력 아이콘·게이지와 화면 가장자리의 저체력 경고는 유지한다.
- 캐릭터 주변의 저체력 효과는 기존 타원과 경고 표시로 복원한다. 화면 가장자리에는 인터페이스 경고만 사용해 테두리가 중복되지 않도록 한다.
- 빈틈은 전투 정보의 글자로 안내하며 몬스터 위의 세 점은 계속 표시하지 않는다.
- 공격·강공격·방어·회피·피격·사망·이중 공격, 장비 효과와 저장 형식은 기존 동작을 유지한다.

검증: 기존 전체 회귀 검사와 저체력·회복·일반/작은 화면 검사를 유지한다. 원화 연결 검사는 기존 도트 스프라이트를 확인하고, 5지역 장면을 그린 뒤 게임 상태가 바뀌지 않는지 확인한다.
