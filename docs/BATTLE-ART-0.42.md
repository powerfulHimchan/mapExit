# 전투 화면 · 0.42.0

선택한 심장 박동형 시안을 실제 게임의 전투 정보, 미니맵, 체력, 두 행동 버튼에 적용한다.

- `battle_chamber.webp`: 인물과 UI가 없는 독립 전투 배경. 10층 구간별 재질 색조와 횃불 빛을 유지한다.
- `battle_actors.webp`: 8열 × 5행. 첫 열은 뒤를 보는 모험가, 나머지는 슬라임·기사·박쥐·거미·골렘·도깨비불·보스. 행은 이끼·침수·수정·잿불·심연 지역이다.
- `battle_equipment.webp`: 10열 × 4행. 검·창·해머·클로·채찍·방패·투구·몸통·바지·신발을 종류별로 매핑한다. 원본 도트의 손잡이 좌표와 착용 부위 좌표를 사용한다.
- 세 원화는 승인된 미리보기를 참고하여 이미지 생성으로 제작했다. 앱에는 배경과 투명 원화만 포함하며 글자와 UI는 실제 상태를 이용해 그린다.
- 기존 공격·강공격·방어·회피·피격·사망·이중 공격 및 장비 교체를 유지한다. 빈틈 안내는 전투 정보에 표시하고 몬스터 위의 세 점은 제거한다.
- 살아 있는 플레이어의 현재 체력이 장착 장비를 포함한 최대 체력의 10% 이하일 때 부드러운 이중 박동, 가장자리의 붉은빛, 체력 아이콘의 파문, 캐릭터 윤곽과 작은 입자가 나타난다. 회복하거나 사망·지상 복귀하면 해제한다.
- 경고 레이어는 입력을 받지 않으며, 게임 상태·전투 수치·저장 형식을 바꾸지 않는다.

검증: 최대 체력과 경계값 및 두 박동의 주기·연속성을 core 테스트로 확인한다. 기기 테스트는 35종 몬스터와 40종 장비 연결, 5지역의 일반/작은 장면, 작은 휴대폰의 공격/방어·회복 후 경고 해제를 검사하고 실행 화면을 저장한다. 기존 전체 기기 회귀 검사도 함께 실행한다.
