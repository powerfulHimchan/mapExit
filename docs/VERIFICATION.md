## 자동 테스트 범위

맵 연결성과 필수 이벤트 배치, 같은 시드의 재현, 손 점유와 장비 개체 수, 클로/방패, 반지 중복·장착 순서, 최대 HP 교체, 목걸이의 비스테이터스 효과, 거래 가격, 일반 사망의 손실/보존, 계승 누적, 교대 전투, 반격 생략, 도주 실패, 보스 해금, 저장 직렬화, 함정 다섯 종류와 시간·오입력·연타·일시정지 경계를 확인했다.

50층 전체 상태 흐름 테스트는 높은 능력치와 체력 복원을 사용하는 검증용 조건으로 모든 층을 통과하고 새 회차의 초기화와 계승을 확인한다. 이 테스트는 실제 난이도나 5분 분량을 검증한 것이 아니다.

## 기기 실행 검증

최종 애플리케이션 코드와 테스트 동기화 변경을 포함한 커밋 `a2736435a747e1013300c71214da3418e4e04e3a`에서 [GitHub Actions 실행 40650351311](https://github.com/powerfulHimchan/mapExit/actions/runs/40650351311)이 성공했다.

- core 테스트 32개, Android lint, debug APK 빌드 통과.
- Android 11(API 30), x86_64, Pixel 2 프로필의 하드웨어 가속 에뮬레이터에서 계측 테스트 1개 통과. 실패·오류·건너뜀 0.
- 첫 화면의 실제 B 버튼 영역에 터치 이벤트를 주입해 1층 탐험 진입 확인.
- 기기 내부에 저장된 JSON을 읽어 층 번호와 일반 저장 여부 확인.
- 탐험·3인칭 전투·타이밍 함정 화면 전환 확인.
- 스크린샷 3장을 수집해 네 구역, 버튼, 일곱 능력치와 골드·기록의 표시를 확인.
- 수정본에서 하단 정보와 메뉴가 잘리지 않는 것을 확인.

계측 테스트는 첫 화면의 접근성 노드가 준비될 때까지 제한 시간 안에서 기다린 뒤 터치한다. 화면 기록은 테스트 종료 후 앱 정리에도 유지되는 Download 경로에 저장하고 CI 검증 아티팩트로 수집한다.

위 APK 크기와 SHA-256은 사용자에게 제공한 로컬 debug APK 기준이다. CI는 저장소에 개인키가 없는 기본 debug 서명을 사용하므로 인증서와 파일 해시가 다를 수 있다. 앱 코드의 동작 검증과 로컬 APK의 동일 서명·무인터넷 권한 검증을 각각 수행했다.

## 실제 플레이로 확인할 내용

- 기기별 화면 가독성·터치감과 앱 재실행 후 복원.
- 층당 약 5분의 탐험 분량.
- 1~50층 난이도와 레벨업·장비 등급 곡선.
- 반지 두 개와 목걸이를 포함한 전체 장비 조합.
- 연속 탐험의 체력 소모와 귀환 선택.

Python의 기존 54만 회 무기 검증은 기준 등급 단일 전투 모델의 결과다. 실제 앱 전체 플레이의 균형을 보장하는 근거로 사용하지 않는다.
