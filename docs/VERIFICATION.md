## 자동 테스트 범위

맵 연결성과 필수 이벤트 배치, 같은 시드의 재현, 손 점유와 장비 개체 수, 클로/방패, 반지 중복·장착 순서, 최대 HP 교체, 목걸이의 비스테이터스 효과, 거래 가격, 일반 사망의 손실/보존, 계승 누적, 교대 전투, 반격 생략, 도주 실패, 보스 해금, 저장 직렬화, 함정 다섯 종류와 시간·오입력·연타·일시정지 경계를 확인했다.

50층 전체 상태 흐름 테스트는 높은 능력치와 체력 복원을 사용하는 검증용 조건으로 모든 층을 통과하고 새 회차의 초기화와 계승을 확인한다. 이 테스트는 실제 난이도나 5분 분량을 검증한 것이 아니다.

## 기기 실행 검증

Android 11 소프트웨어 에뮬레이터에서 APK 설치는 성공했다. 이후 에뮬레이터의 Settings/System UI 응답 불가와 작업 환경 연결 중단으로 실행·터치·저장 재개 및 화면 검증을 완료하지 못했다. 앱 실행 검증 통과로 간주하지 않는다.

GitHub Actions 실행 40646935506에서 core 테스트·lint·APK 빌드와 Android 11 계측 테스트 1개가 통과했다. 다만 테스트 종료 시 앱 외부 폴더가 정리되어 후속 스크린샷 수집이 실패했다. 화면 기록은 테스트 종료 후에도 유지되는 Download 경로로 옮겼으며, 실제 B 버튼 터치와 저장 파일 확인을 계측 테스트에 추가해 다시 검증한다.

## 실제 플레이로 확인할 내용

- 기기별 화면 가독성·터치감과 앱 재실행 후 복원.
- 층당 약 5분의 탐험 분량.
- 1~50층 난이도와 레벨업·장비 등급 곡선.
- 반지 두 개와 목걸이를 포함한 전체 장비 조합.
- 연속 탐험의 체력 소모와 귀환 선택.

Python의 기존 54만 회 무기 검증은 기준 등급 단일 전투 모델의 결과다. 실제 앱 전체 플레이의 균형을 보장하는 근거로 사용하지 않는다.
