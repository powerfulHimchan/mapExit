# 준비 화면·뒷면 장비·몬스터 확대 · 0.48

준비 화면의 돌벽·입구·상인·비품을 전투 원화와 같은 푸른 돌과 따뜻한 횃불의 픽셀 스타일로 교체했다. 중앙 플레이어는 실제 전투 캐릭터와 팔·무기·착용 장비를 함께 그린다. 준비 메뉴 여섯 개도 동일한 재질의 새 아이콘을 사용한다. 준비 배너는 가로 비율을 보존하고 화면 비율에 따라 중앙을 자른다.

정면 장비 아이콘을 뒷모습에 붙이던 문제를 별도 뒷면 장비 원화로 해결한다. 기본/가죽/중갑 투구와 몸통·바지·부츠, 네 방패를 전부 연결했다. 등판·뒷목·뒤꿈치·방패 안쪽 가죽 손잡이를 그리며, 기존 자세별 위치/회전과 등급의 금속 색상을 사용한다. 방패 손은 안쪽 손잡이 위에 그린다. 몸 앞쪽 목걸이 펜던트와 손바닥 반지는 뒷모습에 표시하지 않는다. 가방·상점의 정면 아이콘은 기존 원화를 사용한다.

전투 몬스터는 기존 명목 너비와 높이를 1.5배로 확대한다. 무기·손·그림자·피격 효과는 같은 단위를 따른다. 큰 보스는 상단 정보 패널 아래 빈 영역 높이의 90%와 화면 좌우 경계 안에 들어오도록 크기와 기준 위치를 제한한다. 일반 몬스터는 목표 배율을 사용하며, 극단적으로 큰 보스는 화면에 맞게 줄어들 수 있다. 전투 수치·공격 시계·판정·저장 형식은 바꾸지 않는다.

검증은 원화 재생성 검사, 전체 core/lint/Android 검사 및 APK 빌드에 더해 모든 방어구 변형의 정면/뒷면 구분과 등급 색상, 가죽/판금의 공격·강공격·방어·회피·쓰러짐 프레임, 일반/작은 휴대폰 준비 화면과 몬스터 7계열 UI 캡처를 사용한다. 캡처는 실제 화면과 렌더러에서 수집하며 시안 그림으로 대체하지 않는다.
