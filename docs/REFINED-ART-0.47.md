# 상자·이야기·버튼 · 0.47.0

- 상자는 전투의 실제 캐릭터 렌더러(착용 장비·팔·손 포함)와 배경을 함께 사용한다. 발견 정보 패널의 실측 높이 아래에 캐릭터와 상자를 배치한다. 상자를 열면 같은 상자의 열린 원화를 사용한다.
- 이야기 장면 21종은 `NarrativeArtwork.storyKeys` 순서로 연결하며 종횡비를 유지해 장면 전체를 표시한다. 대사·진행·다시 읽기·저장 상태는 그대로다.
- `gameButtonSurface`가 전투의 `battlePanel`을 공통 사용한다. 누름·비활성·선택 상태와 접근성 역할은 유지한다.
- 방어·회피의 선택 시각과 공격 시작 시각을 분리한다. 몬스터 공격 시작은 500ms 뒤, 타격은 그로부터 기존 320ms 뒤다. 방어 자세는 즉시 준비하고 대기 중 유지한다. 체력 표시·피해 팝업·반격·입력 잠금은 지연된 공격 시각에 연결된다. 전투 계산·확률·저장 포맷은 변경하지 않는다.

원화는 전투 참조 이미지의 금발·녹색 의상, 이끼 낀 푸른 석조와 횃불의 색·재질에 맞춰 이미지 생성으로 제작했다. 제작 프롬프트는 `art/refined047/PROMPTS.md`에 보관한다. 원본은 런타임 drawable과 동일한 PNG이며 이미지 내용의 자동 재생성은 하지 않는다.
