# 0.40 아이템 확장

기존 저장 파일의 아이템과 수치는 그대로 유지한다. 신규 필드는 기본값으로 읽는다.

## 장비

- 기존 무기 20종, 방어구/방패 20종. 각 계열에 접두사 5개와 무접두사 조합: 총 240개.
- 종류와 이름은 `WeaponCatalog`, `ArmorCatalog`, `PrefixCatalog`를 기준으로 한다.
- 접두사 능력치는 기존 기본 능력치 및 보스 추가 옵션과 별도로 저장한다.
- 접두사의 양수 옵션은 생성 등급만큼 적용하고 강화마다 기본 증가량을 한 번 더 더한다. 음수 옵션은 고정한다.
- 기본 장비 강화, 접두사 강화, 보스 옵션이 서로 중복 계산되지 않는다.
- 합성은 접두사 ID/성장 단계까지 같은 아이템끼리만 가능하다.
- 기존 장비에 새 접두사를 소급 부여하지 않는다.
- 상자/일반 전리품/상점의 무작위 장비와 보스/도전자 무기에서 새 종류와 접두사가 나온다.
- 일반 반지 12종, 업적 반지 2종(귀환자의 인장/심연의 인장), 목걸이 10종.
- 심연의 인장: 서로 다른 회차에서 50층 보스 3회 처치 후 업적 보상 수령.

## 강화 소모품 21종

| 능력치 | 영구 열매 | 현재 층 비약 | 120초 물약 |
|---|---:|---:|---:|
| 최대 체력 | +5 | +20% | +35% |
| 공격력 | +1 | +20% | +30% |
| 방어력 | +1 | +25% | +40% |
| 민첩 | +1 | +20% | +35% |
| 치명타 확률 | +0.2%p | +10%p | +15%p |
| 치명타 공격력 | +1%p | +25%p | +40%p |
| 행운 | +1 | +10 | +15 |

- 영구 보너스는 별도 상태로 저장하여 사망/귀환/다음 회차에도 보존한다. 보스/도전에서 낮은 확률로 지급하고 지정 업적에서는 확정 지급한다. 상점과 일반 상자에서는 나오지 않는다.
- 비약은 층/도전 맵을 떠나거나 귀환/사망하면 해제한다. 같은 층 중복 사용은 아이템을 소비하지 않는다.
- 물약은 층 이동 후에도 유지하며, 같은 물약을 재사용하면 지속시간을 갱신한다. 귀환/사망 시 해제한다.
- 탐험/이동/공격 차례/방어 차례/함정/도전에서만 시간이 흐른다. 메뉴/지도/스토리/백그라운드에서는 멈춘다. 재실행 시 저장된 남은 시간을 복구한다.
- 같은 능력치의 임시 효과는 강한 하나만 적용한다. 시간제 효과 만료 시 남은 층 효과가 다시 적용된다.
- 최대 체력 임시 강화는 즉시 회복하지 않는다. 효과 종료 시 현재 체력이 줄어든 최대 체력을 넘지 않게 보정한다.
- 전투에서는 공격 차례에 강화 소모품 메뉴를 열 수 있고, 성공적으로 사용하면 방어 차례가 된다. 취소/실패 시 차례와 아이템을 소비하지 않는다.
- 가방에서 전체/장비/회복/영구 성장/층 강화/시간 강화/강화서를 구분한다. 활성 효과는 횡스크롤 표시줄에 남은 시간 또는 현재 층으로 표시한다.

## 목걸이 신규 효과

- 치유: 회복약 회복량 +15%, 강화당 +5%p.
- 수련: 전투 경험치 +15%, 강화당 +5%p.
- 황금: 전투/상자 골드 +15%, 강화당 +5%p. 의뢰 보상 제외.
- 지속: 시간제 물약 지속시간 +25%, 강화당 +5%p. 사용 시 장착 여부를 기준으로 확정.
- 불굴: 출정당 1회 치명 피해를 입으면 최대 HP 20%로 생존. 강화당 +5%p, 최대 50%. 장비 교체/재실행으로 횟수를 복구하지 않는다.

## 그래픽과 검증

`tools/item_expansion_art.py`에 신규 도트 아이콘 48종을 정의하고 기존 아틀라스 생성기에 연결했다. 접두사는 계열 내 5가지 문양/색상 배지로 구분한다. 종류별 외형과 등급 색상은 장착 화면과 전투에도 동일하게 적용한다.

`ItemExpansionTest`는 240개 조합, 강화/합성, 중복 효과, 만료/일시 정지, 영구 보너스 저장/회차 유지, 전투 차례, 불굴 재사용 방지, 새 업적을 검증한다. `ItemExpansionUiTest`는 신규 아이콘과 접두사별 그림 구분, 가방 필터, 상세 화면, 전투 사용 후 상태를 확인하고 기기 캡처를 남긴다.

로컬 최종 확인: 핵심 테스트 325개 성공(실패/건너뜀 0), Android Lint, 디버그 APK 및 Android 테스트 APK 빌드 성공, 아틀라스 160종 원본 일치 확인. 실제 Android 기기 테스트는 아직 실행하지 않았으며 원격 검증 후 병합해야 한다.
