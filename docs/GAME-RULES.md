# 현재 게임 수치와 등장 규칙 (0.14.0)

이 문서는 실제 Kotlin 로직의 수치를 설명합니다. 기본 맵은 15×15이며 총 50층입니다.

## 스테이터스

장착 후 수치 = (성장한 기본 수치 + 장비 기본 가산 + 보스 추가 옵션 가산) × (1 + 장비 비율 보정의 합).
양손 무기는 두 슬롯을 점유해도 기본 수치와 추가 옵션을 한 번만 합산합니다.

| 항목 | 현재 효과 | 성장 1포인트 |
|---|---|---:|
| 최대 체력 | 생존량. 회복약은 최대 체력 35%, 회복 장소는 45%를 회복합니다. 재장착으로 현재 체력이 회복되지는 않습니다. | +25 |
| 공격력 | 적에게 주는 직접 피해에 비례합니다. 명중률은 바꾸지 않습니다. | +6 |
| 방어력 | 받은 전투 피해에 100/(100+방어력)을 곱합니다. 방어 100이면 절반, 200이면 1/3입니다. 완전 방어 확률도 올립니다. | +5 |
| 민첩 | 회피와 도주 성공률을 올립니다. 공격 속도·추가 턴·명중률·장애물 입력 시간은 바꾸지 않습니다. | +3 |
| 치명타 확률 | 명중한 공격이 치명타가 될 확률. 최종 0~65%로 제한됩니다. | +1.5%p |
| 치명타 공격력 | 치명타의 피해 배율. 150%면 1.5배. 최종 100~400%로 제한됩니다. | +8%p |
| 행운 | 일반 몬스터의 아이템 드롭 확률과 방어 행동의 완전 방어 확률을 올립니다. 등장 배치·상자 매복·보스 옵션 추첨에는 적용되지 않습니다. | +3 |

### 전투 공식

- 일반 공격: 명중률 95%, 피해 = 공격력 × 100/(100+적 방어력).
- 강공격: 명중률 70%, 위 피해의 1.4배.
- 치명타이면 위 피해에 최종 치명타 배율을 곱합니다.
- 방어 행동: 방어력 적용 후 피해를 20% 더 줄입니다. 방패를 장착했다면 총 30% 줄입니다.
- 완전 방어 확률 = 2% + 12%×방어력/(방어력+200) + 10%×행운/(행운+80). 상한 24%, 발동하면 피해 0.
- 회피 성공률 = 10% + (민첩-적 정확도)×0.9%p, 최저 3%·최고 60%. 실패하면 방어 행동의 추가 감소 없이 피해를 받습니다.
- 도주 성공률 = 35% + (민첩-적 정확도)×0.6%p, 최저 15%·최고 85%.
- 일반 몬스터 드롭 확률 = 25% + 행운×0.3%p, 최고 65%. 행운 0/10/100일 때 25/28/55%입니다.
- 몬스터 치명타는 10% 확률·1.5배입니다.
- 장애물 실패 피해 = 최대 체력의 15% + 층수×2이며 방어력·민첩·행운으로 경감되지 않습니다.

## 몬스터·상인·NPC·상자의 배치

걸음마다 확률을 굴리지 않습니다. 층 생성 시 시작점과 출구를 제외한 통로에 다음 수량을 중복 없이 무작위 배치합니다. 기본 15×15 미로의 통로는 97칸, 배치 후보는 95칸입니다. 위치·경로가 달라 실제로 만나는 횟수는 탐험 경로에 따라 다릅니다.

| 이벤트 | 층당 수량 | 후보 95칸 중 비중 |
|---|---:|---:|
| 일반 몬스터, 1~14층 | 7 | 약 7.37% |
| 일반 몬스터, 15~29층 | 8 | 약 8.42% |
| 일반 몬스터, 30~44층 | 9 | 약 9.47% |
| 일반 몬스터, 45~50층 | 10 | 약 10.53% |
| 보물상자 | 4 | 약 4.21% |
| 상인 | 1 | 약 1.05% |
| 미션 NPC | 1 | 약 1.05% |
| 회복 장소 | 2 | 약 2.11% |
| 장애물 | 3 | 약 3.16% |

위 비중은 임의의 후보 칸에 대한 배치 비율이며, 한 걸음을 걸을 때의 독립 확률은 아닙니다. 행운으로 위 수량은 늘어나지 않습니다. 시작점은 안전하고 출구는 시작점에서 가장 먼 통로입니다. 같은 칸의 일반 몬스터·상자·회복·장애물은 처리 후 반복 보상을 주지 않습니다.

- 일반 몬스터 외형은 슬라임·기사·박쥐를 각각 1/3로 선택합니다. 현재 수치는 외형과 무관하게 층에 따라 증가합니다.
- 일반 몬스터 HP = 300+26×층, 공격력 = 65+4×층, 방어력 = 20+1.8×층, 정확도 = 10+0.3×층.
- 10·20·30·40·50층 출구에서는 아직 그 맵의 보스를 잡지 않았다면 보스가 등장합니다. HP 1.7배·공격력 1.2배이며, 보스는 일반 몬스터 배치 수와 별도입니다.
- 상자를 열면 20%는 몬스터, 80%는 아이템과 골드입니다. 상자 몬스터는 배치된 일반 몬스터 수와 별도입니다.
- 보물의 목걸이가 있으면 정상 보물 상자에서 추가 아이템을 받을 확률이 25%입니다.
- 장애물 종류는 다섯 종류를 각각 20%로 선택합니다.
- NPC는 진행 중인 의뢰가 없으면 한 가지 의뢰를 제시합니다. 진행 중이면 상태/보상을 확인합니다. 50층에서는 남아 있는 몬스터·상자에 맞춰 달성 가능한 의뢰를 제시합니다.

## 층별 장애물 난이도

준비 시간은 1초로 유지합니다. 입력 제한 시간 = 2000ms - (층-1)×10ms이며 1~50층 범위로 보정합니다. 함정의 목걸이는 제한 시간을 25% 늘리고 기억 제시 시간도 25% 늘립니다. 이미 저장된 진행 중 장애물은 생성 당시 시간을 유지합니다.

| 층 | 입력 제한 | 솥 입력 수 | 벽 연타 수 | 기억 길이 | 칼날이 완전히 내려간 구간 |
|---|---:|---:|---:|---:|---:|
| 1 | 2.00초 | 2 | 4 | 3 | 약 0.60초 |
| 10 | 1.91초 | 2 | 4 | 3 | 약 0.57초 |
| 25 | 1.76초 | 3 | 5 | 4 | 약 0.53초 |
| 50 | 1.51초 | 4 | 6 | 5 | 약 0.45초 |

기억 제시 속도는 한 동작당 약 333ms에서 304ms까지 서서히 빨라집니다. 길이가 늘어도 전체 패턴이 보이도록 총 제시 시간은 동작 수에 비례합니다. 칼날은 실제 완전히 내려간 시간에 점프, 나무봉은 닿기 전 몸 숙이기 한 번이라는 조작을 유지합니다. 정답 버튼이나 입력 순서를 텍스트로 표시하지 않습니다.

## 무기 5계열·20종

같은 계열의 네 무기는 일반 상점·일반 드롭·정상 보물상자에서 생성됩니다. 계열이 선택된 뒤 세부 종류 네 가지 중 하나를 균등 추첨합니다. 기존 저장의 장비 이름과 수치는 바꾸지 않습니다.

| 계열 | 세부 종류와 특성 |
|---|---|
| 검 | 장검: 균형 / 레이피어: 공격력↓·치명타 피해↑ / 군도: 공격력↑·치명타 피해↓ / 팔시온: 공격력과 치명타 피해의 중간 교환 |
| 창 | 장창: 균형 / 할버드: 공격력↑·방어 손해↑ / 삼지창: 공격력↓·치명타 피해↑·손해 완화 / 랜스: 공격력·치명타 피해↑·확률 손해↑ |
| 해머 | 전투망치: 균형 / 대형 망치: 높은 공격력·큰 생존 손해 / 철퇴: 공격·치명타 피해↓·손해 완화 / 모닝스타: 공격력↓·치명타 피해↑ |
| 클로 | 너클클로: 균형 / 갈고리 클로: 공격력↑·민첩↓ / 바람발톱: 공격력↓·민첩↑ / 카타르: 공격력 중심의 중간 교환 |
| 채찍 | 가죽채찍: 균형 / 사슬채찍: 공격력↑·민첩↓ / 가시채찍: 치명타 피해↑·확률 손해↑ / 유연한 채찍: 공격력↓·민첩↑·확률 손해 완화 |

창·해머는 계속 양손 무기이고, 검·클로·채찍은 한손 무기입니다. 같은 계열에서 공격력만 올려 다른 무기를 완전히 대체하도록 하지 않고 특성 교환을 둡니다. 세부 계수는 `core/.../WeaponCatalog.kt`, 계열 기준값은 `balance/weapons.json`입니다. 기존 Python 밸런스 도구는 계열 기준 조합을 검사하며 세부 무기·보스 옵션 전체 조합의 균형까지 보장하지 않습니다.

### 보스 무기

10층마다 보스를 잡으면 무기 20종 중 하나를 반드시 1개 지급합니다. 이름은 `수문장의 ...`이며 기본 무기 수치에 양수 추가 옵션을 붙입니다. 동일 스테이터스 옵션은 중복되지 않습니다.

- 10·20층: 옵션 2개 / 30·40층: 3개 / 50층: 4개.
- 최대 체력·공격력·방어력·민첩·치명타 확률·치명타 공격력·행운 중에서 추첨합니다.
- 각 옵션의 기준값에 80~120% 난수 배율을 적용합니다. 장비 등급을 T라고 하면 HP 18T, 공격 5T, 방어 4T, 민첩/행운 3T, 치명타 확률 (1.5+0.3T)%p, 치명타 피해 (8+1.2T)%p입니다.
- 기본 등급은 일반 무기와 같은 층별 규칙인 `1+floor((층-1)/10)+0 또는 1`입니다. 추가 옵션은 기본 수치를 덮어쓰지 않습니다.
- 승리 화면·가방·장비 상세에서 기본 수치와 추가 옵션을 확인할 수 있습니다. 장착 비교에도 추가 옵션이 반영됩니다.
- 옵션은 획득 시 한 번만 굴리고 저장합니다. 재접속·장착 교체로 다시 굴리거나 중복 지급하지 않습니다.

실제 효과는 `Equipment.kt`, `GameEngine.kt`, `Defense.kt`, `Growth.kt`, 배치는 `MapGenerator.kt`, 장애물은 `Traps.kt`를 기준으로 합니다.
