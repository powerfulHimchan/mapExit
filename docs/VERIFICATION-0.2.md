# MapExit 0.2.0 검증

기준 main: `0d123aa` (0.1.0). 변경과 최신 CI 결과는 [PR #3](https://github.com/powerfulHimchan/mapExit/pull/3)에서 확인합니다.

## 로컬 결과

- 기존 게임 규칙 테스트 32개와 상황별 버튼 테스트 15개, 총 47개 통과.
- Android lint 오류 0. 기존 세로 고정·백업 및 API 사용 경고는 보고서에 기록.
- Android 앱과 계측 테스트 Kotlin 컴파일 통과.
- v1 저장 구조와 앱 ID를 유지. 이전 선택 위치가 직접 버튼 입력을 바꾸지 않음을 확인.

## Android 11 자동 검증 구성

실제 터치 이벤트를 사용하는 계측 테스트 2개를 CI에서 실행합니다.

- 출정 준비 → 상점 → 회복약 3개 구매 → 장비 상세 비교 → 왼손 장착 → 던전 진입.
- 저장 JSON과 새 모델의 복원 확인, 화면 재생성 후 이동.
- 일반 공격·강공격·방어·회피의 즉시 실행과 길게 눌러 회복약 1회 사용.
- 기본 화면과 720×1280 화면에서 메인 장면·미니맵·양쪽 버튼의 표시 영역 확인.
- 출정 준비·장비 비교·상점·탐험·전투·함정·작은 화면의 PNG 7장을 검증 아티팩트로 수집.

로컬 테스트 통과와 에뮬레이터 실행 결과, 실제 휴대폰 플레이 확인은 구분합니다. 전체 난이도·층당 플레이 시간·기종별 터치감은 실제 플레이에서 추가 조정할 항목입니다.
