# 전투 도트와 동작 프레임 · 0.44.0

2번 정교한 도트 시안의 방향을 기존 게임의 도트 팔레트와 장비 구조에 맞춰 적용한다. 전투 인터페이스와 게임 규칙은 유지한다.

## 원화

- 논리 좌표는 기존 32픽셀 폭을 유지하고, 전투용 원화는 64픽셀 폭의 더 촘촘한 격자로 제작한다. 머리카락·후드·옷 주름·봉제선·버클·부츠와 금속 날/테두리를 추가한다.
- 몸에 무기를 합쳐 그리지 않는다. 몸·소매·팔 보호구·손가락·실제 장착 무기·방패·방어구가 독립 레이어다.
- 캐릭터 82프레임: 대기 2, 무기 5계열의 공격/강공격 각 6, 방어/회피 각 6, 피격/사망 각 4.
- 몬스터 630프레임: 기존 5지역 35종 각각 대기 2, 공격 6, 방어 2, 피격 4, 사망 4. 지역별 종의 실루엣과 색을 유지한다.
- 장비 및 팔/손 레이어 53개. 무기 종류·등급 색·접두 배지와 원래 손잡이 좌표를 유지한다. 방어구 착용에는 접두 배지를 그리지 않는다.

## 연결과 메모리

`tools/battle_motion_art.py`의 픽셀 도형과 팔레트가 수정 가능한 원본이다. `python3 tools/build_pixel_sprites.py`로 기존 도트와 함께 3개 PNG 아틀라스 및 `MotionAtlas.kt`를 생성한다. `--check`는 원본과 출력 픽셀/메타데이터가 일치하는지 확인한다. 생성에는 Python 표준 라이브러리만 사용한다.

`MotionArtwork`는 아틀라스를 한 번 읽고 프레임의 사각형을 선택한다. 등급/접두 색을 적용한 장비는 최대 128개로 캐시한다. 매 프레임 디코딩하지 않고, 보간 없이 가장 가까운 픽셀로 표시한다. 모든 텍스처는 한 변 4096픽셀 이내다.

몸 프레임의 어깨 좌표에 소매와 팔 보호구를 연결하고, 손잡이 위에 손가락을 그린다. 방어 시 방패 위치, 회피·사망 시 몸과 착용 장비의 높이도 함께 맞춘다.

`SpriteFrames`는 기존 `BattleAnimation`의 320ms 타격 시점과 760ms 동작 길이를 사용한다. 연속 공격과 자동 반격은 기존 개별 타격 시계를 사용한다. 피해·치명타·턴·저장·장비 능력치를 변경하지 않는다.

## 검증

core 테스트로 타격 경계, 동작 종료, 피격/사망 우선순위와 개별 타격 시계를 확인한다. 기기 테스트에서 모든 원화 셀의 투명도/경계, 무기별 일반·강공격 6단계, 방어·회피, 실제 장비 등급 색 변화, 모든 지역 몬스터의 공격·피격·사망을 확인한다. 렌더링 전후 저장 상태가 같은지도 검사한다.

일반·작은 전투 장면 및 대표 동작 프레임을 저장하고, 기존 전체 기기 회귀 검사도 수행한다.
