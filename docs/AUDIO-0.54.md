# 0.54.0 오디오 적용

던전 1–10 / 11–20 / 21–30 / 31–40 / 41–50층, 전투, NPC·상인, 장애물 음악에 선택한 B안 8곡을 연결한다. 같은 곡은 프레임마다 재시작하지 않으며 메뉴에서는 원래 장면의 곡을 유지한다. 인트로는 기존 음악을 유지한다.

선택한 음색과 멜로디를 유지하면서 16마디 OGG 루프로 렌더링한다. 샘플 끝의 페이드와 무음 대신 잔향을 시작 부분으로 연결한다. 효과음 42개는 WAV로 포함한다. 모두 오프라인 재생한다.

번호가 지정되지 않은 효과음은 이번 적용 요청에 따라 장면에 맞춰 선택했다. 파일별 선택안과 SHA-256은 `AUDIO-SELECTION-0.54.json`에 기록한다.

공격 효과음은 타격 프레임에 맞추며 방어 준비 500ms, 연속 공격, 반격, 치명타와 처치·레벨업의 각 시점을 구분한다. 빗나감에는 무기 파일에 포함된 타격음을 사용하지 않는다. 발걸음은 좌표 이동에서만 재생하며 1–10층은 흙, 이후에는 돌 질감을 사용한다.

앱 백그라운드·오디오 포커스 상실 시 효과음과 예약된 소리를 취소한다. 복귀 시 현재 음악만 재개한다. 장면 전환은 380ms 교차 페이드로 처리한다. 오디오 실패는 게임 진행이나 저장을 중단하지 않는다.

단위 테스트는 층 경계, NPC·상자·상점·전투 메뉴, 방어 지연, 연속 공격, 반격·치명타·처치, 빗나감, 스냅샷을 검사한다. 기기 테스트는 포함 오디오 컨테이너와 앱 백그라운드·복귀를 검사한다.

기본 APK의 패키지는 기존 `com.powerfulhimchan.mapexit`를 유지한다. 이전 개발 서명 키가 없는 환경에서 기존 앱·데이터를 건드리지 않고 오디오를 확인하려면 `-PaudioPreview=true`로 별도 설치본을 만들 수 있다. 이 경우 패키지는 `.audiopreview`, 표시 이름은 `한 층만 더 · 오디오`가 된다. 별도 설치본은 독립된 새 저장 데이터를 사용한다.
