# 첫 플레이 및 수정 가이드

## 설치와 조작

Android 8.0(API 26) 이상 기기에서 debug APK를 설치한다. 네트워크 연결이나 계정이 필요 없다.

- A/B: 각 버튼에 표시된 행동을 바로 실행.
- 지상 준비와 상점/장비 목록: 화면을 터치해 선택.
- 함정은 A/B를 탭한다. 나무봉은 동작 시작과 신호에 맞춘 해제를 두 번의 탭으로 입력한다.

지상에서 1층 탐험을 선택하면 출발한다. 통로는 자동으로 이동하고 갈림길·시설·전투·함정에서 멈춘다. 이동 중 B를 누르면 멈출 수 있다.

전투는 공격 행동 선택, 몬스터 공격에 대한 방어·회피 선택을 번갈아 진행한다. 강공격은 명중률이 낮고, 회복약도 공격 차례를 사용한다. 도주에 실패하면 방어 차례로 넘어간다.

층 출구에서 다음 층 진행 또는 지상 귀환을 고른다. 10층마다 출구의 보스를 처치해야 이동 장치가 활성화된다. 지상에서 장비 교체·성장 배분·골드 보관을 할 수 있다.

일반 사망 시 아이템·착용 장비·소지 골드를 잃고 성장·보관 골드·장치 해금은 유지한다. 계승 장비도 일반 사망 시 소실된다.

50층 클리어 후 새 장비 한 개를 선택한다. 현재 보유한 기존 계승 장비는 모두 자동 보존한다. 성장·소지/보관 골드·장치는 초기화되고 1층부터 새 회차를 시작한다. 계승 장비는 가방에 들어가므로 필요한 장비를 직접 착용한다.

## 테스트 메뉴

지상 준비 화면의 **테스트 메뉴**에서 다음 네 가지를 선택한다.

- 장애물 피하기: 다섯 종류 중 하나를 선택.
- 전투.
- 상인.
- 미션 NPC 대화.

상단의 **테스트 목록**으로 다른 항목을 선택하고 **테스트 종료**로 원래 진행에 돌아간다. 테스트 모드는 일반 저장과 분리되며 장비·골드·진행을 덮어쓰지 않는다. 앱을 종료한 뒤 다시 실행할 때도 일반 저장으로 시작한다.

## 수정할 위치

| 수정 대상 | 파일 |
|---|---|
| 무기 능력치·방패·공격 명중률·강공격 배율·회피와 방어 공식 계수 | `balance/weapons.json` |
| 장비 등급·반지·목걸이 효과·가격 | `core/.../Equipment.kt` |
| 층 크기·몬스터/시설 배치 수 | `core/.../MapGenerator.kt` |
| 함정 제한 시간·패턴 길이·연타 횟수 | `core/.../Traps.kt` |
| 몬스터 성장·레벨업·보상·사망·계승 흐름 | `core/.../GameEngine.kt` |
| 화면 배치·도트 모양·색상 | `app/.../GameScreen.kt` |
| 저장·불러오기·앱 생명주기 | `app/.../MainActivity.kt` |

`core/...`는 `core/src/main/kotlin/com/powerfulhimchan/mapexit/core/`, `app/...`는 `app/src/main/java/com/powerfulhimchan/mapexit/` 아래를 뜻한다.

Gradle이 `balance/weapons.json`을 core 모듈의 생성 소스에 포함한다. 앱과 Python 검증 도구가 같은 무기 수치를 읽는다. JSON을 수정한 뒤 APK를 다시 빌드한다. 이미 획득한 장비에는 생성 당시 속성이 저장되므로 새 수치 비교에는 테스트용 새 장비를 지급하거나 새 테스트 층을 사용한다.

## 확인할 항목

1. 실제 기기에서 버튼 크기와 네 영역의 글자 가독성이 적절한가.
2. 함정 다섯 종류에서 성공·실패가 납득 가능한가.
3. 보통 탐험 시 한 층이 약 5분인가. 이 값은 목표이며 제한 시간이 아니다.
4. 무기별 생존과 전투 속도의 장단점이 느껴지는가.
5. 귀환을 선택할 만한 위험과 보상이 있는가.

첫 버전은 기능과 저장 흐름을 검증하는 단계다. 층당 실제 소요 시간, 1~50층의 난이도 곡선, 장비·반지·목걸이 전체 조합은 기기 플레이를 통해 추가 조정한다.

입력 로그를 파일로 내보내는 기능, 자동 입력 재생 UI와 배속 UI는 아직 제공하지 않는다. 고정 시드와 게임 상태 JSON, 순수 Kotlin 테스트를 이용해 문제를 재현한다.

## 0.2.0 화면과 직접 조작

지상은 출정 준비 화면입니다. 장비·가방·상점·성장·보관소·기록은 터치로 선택합니다. 장비 상세는 슬롯별 교체 후 능력치 변화를 보여주며, 회복약은 1/3/5개 단위로 구매할 수 있습니다. 지하 1층 진입 버튼은 하단에 고정되고, 해금한 장치는 준비 화면 목록에 표시됩니다.

던전에서는 별도 선택 리스트 없이 버튼에 적힌 행동을 즉시 실행합니다.

| 상황 | A | B |
|---|---|---|
| 앞뒤가 열린 직선 통로 | 앞으로 이동 | 뒤로 한 칸 이동 |
| 공격 차례 | 일반 공격 | 강공격 |
| 방어 차례 | 방어 | 회피 |
| 상자·회복·상인·NPC | 해당 이벤트 실행 | 지나가기 |
| 통로 자동 이동 중 | 이동 중 표시 | 멈추기 |
| 함정 결과 | 결과 표시 | 자동 복귀 |

갈림길의 방향은 현재 시선을 기준으로 표시합니다. 세 방향은 B의 `다른 방향`, 네 방향은 `앞 / 뒤 방향`과 `좌 / 우 방향`으로 나누어 최대 두 단계에서 갈 길을 고릅니다. 상단의 `방향 처음`으로 첫 방향 화면으로 돌아갑니다. 뒤로 이동은 시선을 유지하고 한 칸만 이동합니다. 다른 이동은 기존처럼 통로를 따라 자동으로 이어지며 갈림길·이벤트에서 멈춥니다.

탐험 상단에서 장비·능력치·가방·기록을 엽니다. 공격 차례의 회복약과 도주도 상단에서 선택하며 방어 차례에는 사용할 수 없습니다. 회복약은 공격 차례를 소비합니다. A/B 버튼은 누른 시간에 따른 보조 기능이 없습니다.

메인 장면은 240픽셀 폭의 논리 해상도로 렌더링하고 최근접 보간으로 확대합니다. 작은 주변 미니맵은 현재 위치 중심 9×9칸을 보여줍니다. 상세 능력치는 준비 화면과 가방/기록 메뉴에서 확인합니다. 기존 v1 저장 형식을 유지하며 이전 선택 위치는 직접 조작에 영향을 주지 않습니다.


## 0.3.0 전투·함정 안내

- 탐험은 1인칭, 전투는 플레이어 뒷모습을 가까이에 둔 3인칭으로 전환합니다. 전투 상단에는 적 이름·현재/최대 HP·체력 바를 항상 표시합니다.
- 공격과 피격 위치에 피해량을 띄웁니다. 치명타·방어·회피·빗나감을 구분하며, 숫자는 실제 줄어든 HP를 기준으로 합니다.
- 적을 처치하면 `전투 승리`와 골드·경험치·아이템 보상을 확인합니다. B로 확인한 뒤 탐험이나 층 클리어 선택으로 돌아갑니다. 확인 전 저장·재실행해도 보상은 중복되지 않습니다.
- 함정 다섯 종류 모두 조작 설명을 먼저 표시합니다. 설명 중에는 타이머가 멈추며 B의 `함정 시작`으로 준비 시간을 거친 뒤 시작합니다. 시작 버튼을 정답 입력으로 처리하지 않습니다. 이미 진행 중이던 이전 저장의 함정은 설명으로 되돌리지 않고 이어갑니다.
- 벽에는 통로 입구의 단면·모서리 돌출·윗면·바닥 접촉 그림자를 추가했습니다.


## 0.4.0 조우와 빠른 함정

- 상자·NPC·상인 칸에 도착하면 플레이어의 뒷모습과 대상을 함께 보여 주는 전용 조우 화면으로 전환합니다.
- NPC는 의뢰 하나만 제시하고 A 수락 / B 거절로 선택합니다. 같은 NPC를 다시 만나거나 저장을 불러와도 제시한 의뢰는 유지됩니다. 진행 중인 의뢰가 있으면 새 의뢰 대신 진행 상태를, 완료했다면 보상 받기를 표시합니다.
- 상자는 A 열기 / B 지나가기를 선택합니다. 지나간 상자는 다시 방문할 수 있습니다. 열면 20% 확률로 몬스터가 등장해 전투에 들어가고, 나머지는 아이템과 골드를 획득합니다. 상자는 한 번만 열리며 몬스터가 나온 경우도 상자 의뢰 진행에 포함합니다.
- 상인은 A 거래하기 / B 지나가기를 선택합니다. 거래와 판매 목록은 터치로 조작합니다. 판매 항목에는 장착 중인 슬롯을 표시합니다. 장착 장비를 팔면 해당 슬롯에서 해제되고, 판매한 ID만 목록에서 즉시 사라집니다. 같은 이름의 다른 장비는 남습니다.
- 함정은 “기억해라”처럼 짧은 문구를 1초 보여 준 뒤 자동 시작합니다. 패턴 기억은 패턴을 추가로 1초 보여 준 뒤 입력합니다. 입력 제한은 기본 2초, 함정 목걸이가 있으면 2.5초입니다. 연타는 4~6회, 유지 후 놓기는 0.45~0.75초 뒤에 신호가 나오므로 짧은 시간 안에 완료할 수 있습니다.
- 함정 성공/실패 결과는 0.9초 표시한 뒤 확인 버튼 없이 탐험으로 돌아갑니다. 사망하면 지상 부활 규칙을 따릅니다. 앱을 잠시 벗어난 동안에는 타이머가 멈춥니다.
- 이전 버전의 수동 함정 안내 화면과 NPC 메뉴를 불러오면 새 흐름으로 이어집니다. 위 0.4.0 규칙이 앞선 버전 설명보다 우선합니다.


## 0.5.0 세밀한 도트 그래픽

- 메인 장면의 논리 해상도는 가로 480도트이며 화면 비율에 맞춰 높이를 정합니다. 캐릭터·몬스터·상자의 화면상 크기를 유지하면서 원화의 도트를 촘촘하게 했습니다. 최근접 보간으로 확대합니다.
- 플레이어 정면/뒷모습, 의뢰 NPC, 상인, 기사·보스는 32×48 원화입니다. 상인과 NPC는 서로 다른 옷과 실루엣을 사용합니다. 슬라임은 투명한 색 층과 반사점, 박쥐는 날개막과 이빨, 보스는 투구·뿔·붉은 갑옷으로 구분합니다.
- 벽돌과 바닥 돌에는 균열·모서리 깨짐·이끼를 넣었습니다. 벽 단면과 재질은 원근에 맞춰 투영되며, 횃불에는 금속 받침·나무 결·불꽃 층과 조명을 표시합니다. 무작위 입자가 매 프레임 바뀌지 않도록 고정된 재질을 사용합니다.
- 검·창·해머·클로·채찍과 방패는 손 위치에 맞춰 표시합니다. 가방·장비·상점·판매·소모품 수량·상세 비교·계승 목록에서도 같은 원화의 아이콘을 사용합니다.
- 지상 성문과 준비 화면, 계승 화면, 상자·회복 장소·출구·상인·NPC, 함정의 금속 장치와 A/B 문자도 같은 도트 스타일로 정리했습니다. 함정의 입력 구간과 진행률은 실제 상태를 기준으로 그립니다.
- 원화 수정은 `tools/build_pixel_sprites.py`의 팔레트와 도형 좌표를 편집한 후 실행합니다. `--check`로 생성된 Kotlin atlas와 원본의 일치를 검사할 수 있습니다.

## 0.6.0 탐험 종료와 장비

- 사망하면 즉시 준비 화면으로 넘어가지 않습니다. 사망 위치, 이번 탐험의 최대 층, 처치한 적, 연 상자, 피한 함정, 탐험 시간과 잃은 소지품을 확인한 후 `준비 화면으로`를 누릅니다.
- 탐험/이동 화면 오른쪽 상단 `지상으로`를 누르면 이동이 멈추고 손실 안내가 나옵니다. `계속 탐험`은 손실 없이 취소하며, `포기하고 귀환`은 사망과 동일하게 모든 장비·아이템·소지 골드를 잃고 결과 화면으로 이동합니다. 층 클리어의 기존 안전 귀환은 그대로 소지품을 보존합니다.
- 장착 현황은 머리, 몸통과 양손, 하체와 반지, 신발의 위치로 표시됩니다. 밝은 아이콘은 착용, 흐린 아이콘은 빈 부위이며 양손 무기는 두 손에 `양손 점유`로 표시됩니다. 장비를 누르면 상세 정보, 빈 부위를 누르면 가방이 열립니다.
- 기존 버전의 진행 중 저장은 현재 층부터 기록을 이어갑니다. 과거 처치/상자/함정/시간은 저장에 없으므로 새 버전에서 측정한 값부터 누적됩니다.

## 0.7.0 이동과 아이콘 메뉴

- 벽과 바닥 무늬가 던전 좌표에 고정되며 한 칸 이동은 600ms 동안 이어집니다. 후진은 시선을 유지하고 회전은 짧은 방향을 사용합니다. 연속 입력 시에도 칸 중심을 거쳐 벽 모서리를 통과하지 않습니다. 층 이동과 앱 일시정지는 카메라를 현재 위치에 맞춥니다.
- 성장 메뉴의 7개 능력치 카드는 아이콘, 현재 수치, 1P 투자 후 수치를 표시합니다. 투자 후 수치는 착용 장비의 백분율 효과와 능력치 상한을 반영합니다. 포인트가 없으면 투자가 비활성화됩니다.
- 상점과 판매는 2열 아이콘 카드입니다. 효과·가격·골드 부족/장착 중 표시를 확인하고 카드를 누릅니다. 구매/판매된 장비는 바로 사라집니다. 회복약은 1·3·5개 수량 카드를 사용합니다.

## 0.8.0 장착 유지 / 준비 메뉴 / 공격 동작

- 장착 부위에서 장비를 착용/해제하면 같은 장착 화면에 남습니다. 빈 부위→가방→장비 상세로 들어가도 착용 후 부위 화면으로 돌아옵니다. 가방에서 시작했다면 가방으로 돌아옵니다.
- 성장 카드는 4열이며 준비 메뉴 6개와 상태 요약에 아이콘을 붙였습니다. 하위 메뉴 상단의 마지막 행동 로그는 제거했습니다. 기록 메뉴의 실제 기록 목록은 유지합니다.
- 던전 상황 설명은 장면 바로 아래의 같은 위치에서 굵은 글자와 대비가 높은 배경/테두리로 표시됩니다.
- 검 베기, 창 찌르기, 해머 내려치기, 클로 연속 긁기, 채찍 휘두르기와 슬라임 점프/박쥐 급강하/기사 베기/보스 내려치기를 표시합니다. 몸·팔·무기가 움직이고 대상은 뒤로 밀리며 타격 시점에 숫자가 나타납니다. 플레이어 피해는 빨간 숫자, 치명타는 큰 숫자와 별도 문구·테두리·섬광입니다.
- 동작은 760ms 동안 재생하며 이 동안 다음 전투 입력을 막습니다. 승리/사망도 마지막 동작을 보여준 후 결과 화면으로 넘어갑니다. 저장에는 이미 확정된 전투 결과를 기록하므로 중단·복원 시 피해나 보상이 중복되지 않습니다.

## 0.9.0 상점 비교 / 행동별 모션 / 메뉴 정리

- 상점 상품 카드 안에서 허용된 부위별 현재 장비 이름·효과와 교체 후 전체 능력치 증감을 표시합니다. 양손 점유로 함께 해제되는 장비도 안내하며 반지는 두 칸을 각각 비교합니다. 비교만으로는 구매·장착·저장 상태가 변경되지 않습니다.
- 일반공격은 짧은 준비 후 공격, 강공격은 깊은 준비 후 큰 전진·몸통 회전과 충격 고리입니다. 방어는 무기를 들어 막고, 회피는 몸을 낮춰 뒤로 빠지며 잔상을 남깁니다. 무기별 특성과 타격 320ms/완료 760ms는 유지합니다.
- 행동 버튼에서 A/B 바로 실행·대기 문구를 제거하고 의미 있는 길게 누르기 안내만 남깁니다. 조우 문구에서 3인칭 전투 시작을 제거합니다.
- 던전 진입·준비 화면으로 버튼을 도트 아이콘/짙은 패널/민트 테두리로 통일합니다.
- 탐험 기록에는 누적 회차·최고 층·클리어·이동 장치·진행 의뢰만 표시합니다. 행동 로그와 다른 메뉴로 이동하는 중복 항목은 제거합니다.

## 0.10.0 던전 HUD

- 레벨업 시 레벨 변화·이번에 획득한 성장 포인트·보유 포인트를 금색 배너로 표시합니다. 마지막 공격 동작 후 표시하며 닫거나 능력치 메뉴를 열기 전까지 유지합니다. 미확인 알림은 저장 복원되며 여러 번 레벨업하면 합산합니다.
- 던전 상단에 장비·능력치 버튼을 추가했습니다. 자동 이동 중에는 이동을 멈추고 메뉴를 열며 복귀 후에도 같은 위치에서 멈춰 있습니다. 전투·함정 중에는 숨겨 메인 장면 공간을 확보합니다.
- 공격/방어 차례는 상황 설명과 적 정보에서 분리해 미니맵 옆 HP 상태 영역에 표시합니다.
- 막다른 길에서 다른 칸으로 이동하면 해당 문구를 제거하고 새 통로·갈림길·이벤트 안내로 갱신합니다.

## 0.11.0 실제 장애물 / 직접 메뉴 / 구매 피드백

- 솥의 뜨거운 물, 바닥 칼날, 좁혀오는 벽, 기억 석판, 천장에서 내려오는 나무봉을 장면에 그립니다. 준비·활성·결과가 동일한 실제 장치를 사용하며 진행에 맞춰 움직입니다.
- 기억 순서는 왼쪽/오른쪽 석판의 점멸로만 보여주고 입력 단계에서는 사라집니다. 모든 장애물의 A/B 정답·입력 금지·지금 놓기 텍스트를 제거합니다. 버튼 이름은 좌우 동작으로 고정합니다.
- 마지막 공격의 피해는 타격 동작 중에만 표시하며 전투 승리 결과에는 남기지 않습니다.
- 돈이 부족한 상점 상품은 이름을 빨간색으로 표시하고 터치하면 일시적으로 골드부족 안내를 띄웁니다. 상시 부족 문구를 제거하고 구매 시도는 아이템·골드를 변경하지 않습니다.
- 탐험 상단에 가방·기록·방향 처음 메뉴, 전투 헤더 안에 회복약·도주 버튼을 추가합니다. 기존 길게 누르기도 호환하지만 모든 기능을 상단에서 직접 실행할 수 있습니다.

## 0.12.0 탭 전용 조작 / 획득품 / 랜덤 맵 / 완전 방어 / 테스트

- 버튼의 길게 누르기 분기를 제거합니다. 가방·기록·방향 초기화·회복약·도주는 상단 버튼으로 실행하고 나무봉도 시작/놓기를 별도 탭으로 처리합니다.
- 골드부족 안내는 화면 중앙에 잠시 표시합니다.
- 실제 앱의 새 던전 진입은 매번 새 난수 시드를 사용하며 저장된 현재 맵은 재접속 시 유지합니다.
- 상자를 열면 획득한 모든 아이템의 아이콘·이름·옵션과 골드를 메인 장면 카드에 표시합니다. 확인하거나 이동하면 닫으며, 저장 복원으로 보상이 중복되지 않습니다.
- 갈림길에서 방향을 선택하면 오래된 갈림길 안내를 지웁니다.
- 방어력과 행운에 비례해 완전 방어가 발생하며 피해 0을 별도 표기합니다. 확률은 점감식이며 최대 24%입니다.
- 공개 테스트 메뉴는 장애물·전투·상인·미션 NPC 네 종류만 제공합니다. 장애물은 종류를 고를 수 있고 테스트 종료 시 원래 진행을 복원합니다.
